# EcoBite Customer App

React Native + Expo + Expo Router + TypeScript. Surplus-food marketplace with customer self-pickup.

```bash
npm install
npx expo start      # or: npm run web / android / ios
npx tsc --noEmit
npm run verify      # foundation checks: routes, mock payment/order/pickup/AI services
```

Naming: the project is **EcoBite Customer App** (package `ecobite-customer-app`). The working folder on the original machine is spelled `Ecobite-custumer-app`; the folder name has no effect on the code, so renaming it is optional.

See `docs/` (MVP, ARCHITECTURE, AI-FLOW) and `CLAUDE.md`.
